# laravel-filament-agents

Placeholder for WAME's Filament agents and skills, by [WAME](https://wame.sk). Part of the `wame` marketplace.

## Status: coming later

This plugin is **intentionally empty**. WAME's first real Filament work lands with **WAME Reality
Phase 1**; the `filament-resource` agent and `wame-filament-patterns` skill will be written from
what that work teaches — not blindly from documentation. Installing this today is a no-op that
reserves the plugin name and marketplace slot.

For Laravel (non-Filament) and Laravel Nova work today, use
[`laravel-agents`](https://github.com/wamesk/claude-code-plugin-laravel-agents) and
[`laravel-nova-agents`](https://github.com/wamesk/claude-code-plugin-laravel-nova-agents).

## Installation

```
/plugin marketplace add wamesk/claude-code
/plugin install laravel-filament-agents@wame
```
